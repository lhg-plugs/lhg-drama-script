# lhg-ds-theme：题材立项（从想法到可拍的题材说明书）

> 目标：把"我想写个短剧"变成一份**可立项、可排期、可判断值不值得拍**的题材说明书。
> 核心纪律：**题材先行，人物第二，剧情第三**——题材错了，剧本越努力越白费。

## 1. 何时使用

- 用户说"我有个想法""想写短剧但不知道写什么" → 全流程
- 用户已有题材，拿不准"这个题材能不能火" → 直接进第 4 节爆款元素打分
- 大纲写到一半发现"越写越没劲" → 打回本 skill 重做题材诊断（多半是题材本身情绪浓度不够）

## 2. 输入与输出

**输入**：一句话想法（越糙越好，如"我想写赘婿""想写萌宝"）+ 可选的目标平台（抖音/快手/小程序剧）+ 可选的集数预期。

**输出**：《题材说明书》一页纸，固定包含：

1. 一句话梗概（含主角身份 + 核心冲突 + 最大看点）
2. 赛道定位（见第 3 节九宫格中的位置）
3. 爆款元素命中清单（见第 4 节，至少命中 3 个才建议立项）
4. 目标观众画像（一句话：谁、为什么看、为什么付费/追更）
5. 体量规划（总集数、单集时长、拍摄周期量级：S/M/L）
6. 红线自查结论（见第 6 节，全绿才放行）

## 3. 赛道九宫格：先定位，再谈创意

短剧赛道按"性别向 × 情绪主菜"划分，先定格子，再在格子里找差异化：

|  | 复仇爽 | 身份爽 | 情感虐 |
|---|---|---|---|
| **男频** | 战神归来、退婚打脸 | 首富赘婿、龙王 | 追妻火葬场（男视角） |
| **女频** | 重生复仇、打脸渣男 | 闪婚大佬、萌宝助攻 | 先婚后爱、替身虐恋 |
| **合家欢/下沉** | 乡村逆袭、婆媳大战 | 草根首富、神医 | 家庭伦理、亲情救赎 |

定位三问：

1. **主情绪是什么？**（爽/虐/甜/悬疑，只能选一个主菜，两个都想要 = 两个都做不好）
2. **观众代入的是谁？**（必须是一个具体的人：28 岁县城宝妈、45 岁小镇男青年……不能是"大众"）
3. **前三集的"情绪承诺"是什么？**（观众看完前三集，应该带着哪种情绪走：愤怒？期待打脸？心疼女主？说不清 = 题材立不住）

## 4. 爆款元素清单：命中 3 个再立项

给题材逐项打勾（✓/✗），命中不足 3 个 → 回炉换题材或叠加元素：

1. **强身份反差**：主角有双重身份（赘婿/首富、保洁/董事长、傻子/神医），反差越大，观众越想看"掉马"那一刻
2. **明确的仇恨对象**：开局 3 集内必须有一个让观众"想骂"的反派（渣男、恶婆婆、势利眼亲戚），没有仇恨就没有追更动力
3. **可预期的爽点**："打脸""掉马""复仇"这类观众能预判、并愿意等的爽点；纯靠意外取胜的题材留存差
4. **高频小反转土壤**：题材天然能装下"每集 3 个反转"（身份、误会、卧底、失忆都是好土壤；纯日常温情题材装不下）
5. **低理解门槛**：一句话能跟没看过的人讲明白（"赘婿其实是首富"✓；"元宇宙赛博朋克伦理困境"✗）
6. **系列化潜力**：这个题材能不能换主角再拍一季（能 = 长线资产；不能 = 一次性消耗品）

## 5. 体量规划：集数不是越多越好

| 体量 | 总集数 | 单集时长 | 特点 |
|---|---|---|---|
| S（试水） | 20–40 集 | 1–1.5 分钟 | 一条主线、一对 CP、一个反派，适合新人练手 |
| M（标准） | 60–80 集 | 1.5–2 分钟 | 主线 + 一条副线，中段需要一次"换地图"（新场景/新反派）防止疲软 |
| L（长剧） | 80–120 集 | 2 分钟左右 | 需要至少 2 次大反转重启（身份再反转、换主舞台），否则后半必崩 |

铁律：**集数由"反转库存"决定**。先数你手里有多少个像样的反转（见 lhg-ds-outline 第 3 节反转库），反转数 × 0.7 ≈ 能撑的集数（每集 3 个反转，但允许 30% 复用变形）。反转不够就砍集数，不要注水——注水集是弃剧重灾区。

## 6. 题材红线自查：有一项不过就停

1. 是否涉及真实历史人物、时政影射？（是 → 停）
2. 是否美化违法犯罪（诈骗、暴力讨债当爽点）？（是 → 停）
3. 是否有低俗擦边当主要卖点？（是 → 停，平台审核必杀）
4. 核心设定是否与某部已知爆款短剧"换皮级"雷同？（是 → 回炉，换核心反转再立项）
5. 主角的三观是否经得起"讲给家里长辈听"？（经不起 → 观众口碑会反噬）

## 7. 题材验证三法：动手前先低成本测试

题材说明书写完别急着进大纲，先过三法验证——改一页纸的成本是改 60 集大纲的百分之一。

**法一：热搜对照法**

1. 去短视频平台热榜找同赛道近 30 天爆款，记下前 3 名的"一句话梗概"
2. 逐项对比：主角身份、核心冲突、最大爽点，我的版本和它们差在哪
3. 通过标准：至少 2 处实质性差异（换主角性别不算，换核心反转才算）
4. 不通过 → 回炉：要么换赛道格子，要么把差异点做到"第一眼就不一样"

**法二：电梯测试**

1. 用 30 秒把一句话梗概讲给一个没看过短剧的朋友听
2. 让对方复述：主角是谁？他最大的爽点/看点是什么？
3. 通过标准：对方能复述出"身份 + 冲突"两要素
4. 不通过 → 梗概太绕，回 lhg-ds-theme 第 2 节重写（多半是低理解门槛那项没过）

**法三：前三集试写**

1. 按 lhg-ds-outline 第 3 节"开局"要求，只写前 3 集大纲
2. 写完问自己：第 4 集我还有东西写吗？第 10 集的高潮在哪？
3. 通过标准：能说出第 10 集的名场面，且和前 3 集不是同一个反转
4. 不通过 → 题材撑不起目标集数：砍集数（M 改 S），或回第 4 节叠爆款元素

三法全过，题材才算"可立项"。只过两法 → 标注风险项再进大纲，不许假装没看见。

### 附：题材说明书（一页纸模板）

```text
【题材】《____》｜赛道：__频__爽 ｜ 体量：S/M/L（__集）
【一句话梗概】____（身份/冲突/看点三要素）
【爆款元素】命中 __/6：____
【目标观众】____（年龄/地域/身份）
【前三集情绪承诺】____
【反转库存】约 __ 个 → 可撑 __ 集
【红线自查】5 条全绿 / 有风险项：____
【验证三法】热搜__ 电梯__ 试写__
```

填完这张纸，题材才算"立项完成"。纸没填完就写大纲，等于没系安全带上高速。

## 8. 反模式

- **题材集邮**："又想复仇又想甜宠又想悬疑"——主情绪只能有一个，其余只能当调料
- **自嗨式创新**："市面上没有的题材"多半是因为"市面上验证过不行"；创新 = 老元素新组合，不是凭空造赛道
- **先写 10 集再立项**：顺序反了。题材说明书一页纸没写完，不许动大纲——大纲是题材的放大器，不是救生圈
- **跟风不跟节奏**："赘婿火了我也写赘婿"——跟风可以，但必须回答"我的版本和爆款差在哪 3 处"，答不出就是炮灰

## 9. 自检与反馈

**质检门**（题材说明书发布前逐项过）：

- [ ] 一句话梗概里同时出现了"主角身份、核心冲突、最大看点"三要素
- [ ] 赛道九宫格位置唯一（说不清是男频还是女频 = 没定位）
- [ ] 爆款元素命中 ≥3 个，且每个都有剧中的具体落点（不是空勾）
- [ ] 目标观众画像具体到年龄/地域/身份三词
- [ ] 反转库存数 ≥ 集数 × 3 × 0.7（见第 5 节公式）
- [ ] 红线 5 条全绿

**标准冒烟用例**：输入"我想写赘婿"，输出必须包含一页纸题材说明书，且爆款元素打分逐项给出 ✓/✗ 及理由，不能只给结论不给过程。

**一键反馈**：发现方法论缺口（如新赛道未覆盖），以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-drama-script/issues，正文写清"题材案例 → 方法论哪里卡住 → 期望补充什么"。
