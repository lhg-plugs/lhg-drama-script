# lhg-ds-episode：单集剧本（分集大纲 → 可拍摄的剧本文件）

> 目标：把大纲里的一行字，翻译成**演员能演、摄影能拍、审计脚本能校验**的单集剧本。
> 核心纪律：**剧本是写给镜头的说明书，不是小说**——能动手的别吵吵，能吵吵的别心里想。

## 1. 何时使用

- 分集大纲已定、用户点名"写第 N 集" → 全流程
- 用户只有一集的想法、想先看一集质量 → 用第 3–6 节写"试写集"（建议试写第 1 集）
- 剧本被审计脚本打出 blocker → 按第 8 节规则逐条改，不要绕开脚本

## 2. 输入与输出

**输入**：分集大纲中该集的一行（剧情 + 反转编号 + 情绪走向 + 卡点）+ 人物小传（前 3 集需要）。

**输出**：单个 Markdown 剧本文件，**必须严格遵守第 7 节文件格式**（审计脚本按该格式解析；格式一错，校验全错）。

## 3. 开场 30 秒：钩子库

短剧观众 3 秒划走。开场 30 秒必须出现一个钩子（在剧本中用 `` 标注），6 类任选：

| 类型 | 写法 | 例子 |
|---|---|---|
| 冲突前置 | 把本集最大冲突的第一秒直接演出来 | 婚礼现场，新郎把婚戒扔在地上："这婚不结了！" |
| 羞辱开场 | 反派先动手，主角先受辱（压弹簧） | 婆婆把离婚协议甩在女主脸上："签了它，滚出我家！" |
| 悬念抛问 | 一个没头没尾的强悬念 | 凌晨三点，男主跪在雨里："求求你，把孩子还给我！" |
| 身份错位 | 让观众先误会，再期待反转 | 保洁员被保安拦在门外，下一秒百辆豪车停在门口 |
| 倒计时 | 明确的时间压力 | "飞机还有 10 分钟起飞，而她还在 30 公里外。" |
| 名场面闪回 | 先给高潮一帧，再回"三小时前" | 先演巴掌落下的慢动作，再切回"三小时前……" |

钩子质检三问：① 前 3 秒有没有一个**具体动作**（不是心理活动）？② 删掉这个钩子，本集还成立吗？（成立 → 钩子是摆设）③ 钩子承诺的冲突，本集真的演了吗？（没演 → 骗观众，下集就跑）

## 4. 分场：短剧的场是"情绪单元"

- 单集场次宜 **2–4 场**：1 场嫌单调，5 场以上观众情绪被切碎
- 一场 = 一个连续时空 + 一个情绪任务（立威/受辱/反转/铺垫），任务写在 `` 行后面
- 转场靠"动作"不靠"旁白"：`摔门而去→下一场已在车里`，不要写"三天后"硬切；必须跳时间就加过渡动作（一杯茶从热到凉）
- 前三集建议只用 1–2 个场景：场景切来切去会打断情绪流（高潮前置的那场戏，一镜到底最有劲）

## 5. 台词：信息优先，短句为王

1. **先给信息**：每句台词先交代身份/冲突/目标，再谈别的。"我是林氏集团董事长"必须出现在羞辱之前，顺序反了观众代入不了
2. **单句 ≤25 字**：超过就拆成两句，或转成动作。一句 40 字的台词，演员念着累、观众听着困
3. **潜台词动作化**：不许写"（心想：他果然是骗我的）"，改成动作——"她攥紧了手里的鉴定书，指节发白"
4. **每场至少一个"钉子句"**：全场最狠的那句台词，要短、要准、要能当切片传播。"天凉了，让姜家破产吧"就是钉子句
5. **称呼统一**：同一人物在全剧本里只能有一个称呼（"林凡"和"小凡"混用 = 人物出场一致性告警）
6. **嘴替角色**：每集安排 1 个路人/配角说出观众的心里话（"这也太欺负人了！"），帮观众把情绪喊出来

## 6. 时长换算：字数即时长

| 内容 | 换算 | 说明 |
|---|---|---|
| 台词 | 字数 ÷ 4.5 ≈ 秒数 | 短剧语速快，按每秒 4.5 个字计（含标点停顿） |
| 动作描写 | 字数 ÷ 10 ≈ 秒数 | 动作行读得快，且常与台词叠演，取保守值 |
| 场景切换 | +2 秒/场 | 转场、空镜、 establishing shot 的保底 |
| 打戏/大场面 | 单独标注 | 无法按字数算，写""明示 |

单集目标时长 **60–150 秒**（1–2.5 分钟）。超了 → 先砍台词（每句压到 25 字内），再砍场次，最后才砍反转——反转是命根子。

## 7. 剧本文件格式（审计脚本解析依据）

以下格式**一个字都不许改**，审计脚本逐行解析：

```markdown
# 《赘婿归来》第 3 集：董事长下跪

林凡（男主，赘婿/首富）/ 苏晴（女主）/ 赵泰（反派，赵家少爷）
90 秒

## 第 1 场
日·赵家宴会厅——赵泰当众羞辱林凡（情绪任务：压）
赵泰把红酒泼在林凡脸上："赘婿也配坐主桌？"
赵泰：一个上门女婿，也敢坐主桌？（把红酒泼过去）
林凡：（擦脸，站着不动）
苏晴：赵泰！你太过分了！
林凡的手机响起，备注"管家"：家族封印解除

## 第 2 场
日·宴会厅外走廊——林凡接电话（情绪任务：转）
（林凡走到走廊，压低声音接电话）
林凡：说。
管家（电话）：少爷，封印已解除，您现在可以动用家族资金。
林凡决定不再隐瞒，当场回去
赵泰追出来，看到百辆豪车停在门口，傻眼

林凡回头，举起手机："天凉了，让赵家破产吧。"——切黑屏
```

格式铁律：

- 标题行 `# 《剧名》第 N 集：集标题`（必须有"第 N 集"）
- `` 行：人名用 `/` 分隔，括号内写身份备注；**台词里出现的所有人名必须在此登记**
- `` 行：纯数字秒数（可选，但写了就会被校验）
- `## 第 N 场`：场次编号从 1 连续递增
- `` 行：时·景 + 一句话 + 括号注明本场情绪任务
- ``：必须出现在预估 30 秒之前的位置（按第 6 节换算累计）
- 台词行：`人名：台词`（中文冒号或英文冒号均可）；括号内为动作/语气提示
- ``：编号连续，每集 3~5 个
- ``：全文件有且仅有一处，放在最后

## 8. 审计脚本会查什么（写完先自查）

确定性规则（`scripts/audit/drama_audit.py`，零第三方依赖）：

- **反转数**：`` 标记 <3 → blocker；编号不连续 → warning
- **钩子位置**：无 `` → blocker；钩子出现在预估 30 秒之后 → warning
- **时长**：预估总时长超出 60–150 秒 → warning；与 `` 偏差 >20% → warning
- **人物一致性**：台词人名未在 `` 登记 → blocker；登记了全集没出场 → warning
- **台词**：单句 >40 字 → warning；单场纯台词无动作行 → warning（"能动手的别吵吵"）
- **场次**：>6 场或 <1 场 → warning；场次编号不连续 → warning
- **卡点**：无 `` → warning；出现 2 处以上 → warning

机器查完，人按 lhg-ds-audit 的评审清单再过一遍（钩子够不够炸、钉子句够不够狠，这些机器查不出）。

## 9. 反模式

- **小说式剧本**：大段心理描写、环境渲染——剧本里每多一句"他心想"，就少一分可拍性
- **钩子后置**：前 30 秒全是铺垫，"精彩的在后面"——短剧没有"后面"，观众 3 秒就划走了
- **反转只标不写**：`` 后面跟一句空话，没有具体的动作/台词/信息变化——标注是给审计看的，内容是给观众看的
- **台词辩论赛**：正反派站着吵 3 分钟——短剧吵架超过 5 句就必须有一个动作打断（泼水、摔杯、耳光）
- **场次观光团**：一集 8 个场景，每个 10 秒——观众连人物脸都没记住，情绪全碎了

## 10. 自检与反馈

**质检门**（剧本文件交付前逐项过）：

- [] 文件格式与第 7 节逐行对照（标题/人物/场次/标记一个不少）
- [] `python3 scripts/audit/drama_audit.py --target <剧本目录>` 零 blocker
- [] 钩子三问全过（第 3 节）
- [] 每句台词 ≤25 字（审计只卡 40 字，人要卡 25 字）
- [] 每场至少 1 个钉子句，全集至少 1 个可切片传播的金句
- [] 通读一遍：把台词读出声，拗口的重写

**标准冒烟用例**：输入大纲行"第 3 集：宴会羞辱→首富掉马"，输出符合第 7 节格式的完整剧本，且审计脚本零 blocker。

**一键反馈**：发现方法论缺口，以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-drama-script/issues，正文写清"剧本案例 → 哪条规则误报/漏报 → 期望怎么改"。
