# /lhg-drama-script:drama-hook —— 钩子专项

用户输入在 `$ARGUMENTS` 中：`[第N集或一句话剧情] [--type 钩子类型]`。

加载 `lhg-ds-episode` 第 3 节钩子库。可分派给 `scriptwriter` agent 起草，但**选择权在用户**。

## 流程

### 1. 定约束
- 确认这是第几集（第 1 集钩子要"高潮前置"，后续集钩子要"承接上集卡点"）、本集情绪任务（压/转/爆）。
- `--type` 指定了类型就按指定类型写 3 版；没指定就从 6 类里挑最贴合本集的 3 类各写 1 版。

### 2. 写 3 版钩子
- 每版包含：钩子正文（台词/动作，30 秒内可演完）+ 类型标注 + 为什么选这个类型（一句话）。
- 3 版之间类型不许重复，情绪强度要有梯度（最炸的放最后，给用户惊喜）。

### 3. 用户拍板
- 把 3 版摆给用户选，**用户没选就不许往下写**。用户可以说"3 版都不行，换 3 类"，那就换 3 类重写。
- 选定后，钩子直接写入剧本 `` 位置，进入 `/lhg-drama-script:drama-episode` 第 3 步。

## 硬规则
- 只给 1 版钩子让用户"将就" → 不许，至少 3 版。
- 钩子超过 30 秒演完 → 重写（短剧没有"慢慢来"）。
- 钩子是心理活动/旁白 → 不许，必须是具体动作或冲突台词。
